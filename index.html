💡 Mode File Lokal Terdeteksi

Kamu membuka index.html langsung melalui klik berkas (protokol file://). Demi alasan keamanan, browser membatasi fungsi fetch() modular saat membuka file langsung dari disk.

Dua Cara Termudah Menjalankan Website:

  1. Deploy ke GitHub Pages: Push ke repository GitHub kamu. Website akan aktif dan termuat 100% otomatis di https://<username>.github.io/<repo>/.
  2. Preview Lokal dengan Python: Jalankan perintah berikut di terminal/PowerShell: 
    python build.py --serve
    atau gunakan ekstensi Live Server di VS Code.
